# Workout Log

개인용 헬스 루틴 및 운동 기록 웹 애플리케이션입니다.

자주 사용하는 운동 루틴을 저장하고, 특정 날짜에 해당 루틴을 불러와 세트별 중량과 반복 횟수를 기록할 수 있도록 개발합니다.

## 주요 기능

* 운동 종목 관리
* 커스텀 운동 등록
* 운동 루틴 저장 및 불러오기
* 날짜별 운동 기록
* 세트별 중량, 반복 횟수, 세트 유형 기록
* 운동 및 세션 메모
* 과거 운동 기록 조회 및 수정
