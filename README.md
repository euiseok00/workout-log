## About

Workout Log는 개인 운동 루틴과 수행 기록을 관리하기 위해 만든 풀스택 웹 애플리케이션입니다.

루틴 기반 운동과 자유 운동을 기록할 수 있으며,  
세트별 중량과 반복 횟수, 이전 운동 기록, 월별 운동 현황을 확인할 수 있습니다.

## 주요 기능

- 회원가입 및 로그인
- 운동 루틴 생성 및 수정
- 루틴 기반 / 자유 운동 기록
- 세트별 중량 및 반복 횟수 기록
- 이전 운동 기록 불러오기
- 캘린더 기반 운동 기록 조회
- 운동 통계 확인
