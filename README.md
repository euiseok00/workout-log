# Workout Log

Spring Boot와 React를 활용한 개인 헬스 루틴 및 운동 기록 웹 애플리케이션입니다.

## Tech Stack

### Frontend
- React
- Vite
- JavaScript
- ESLint

### Backend
- Java 21
- Spring Boot
- Spring Web
- Spring Data JPA
- Spring Security
- Validation

### Database
- PostgreSQL

### Infrastructure
- AWS EC2
- Docker Compose
- Nginx
- HTTPS
- Cloudflare Pages
- GitHub Actions

## MVP

- 회원가입 및 로그인
- 운동 종목 관리
- 운동 루틴 생성 / 수정 / 삭제
- 루틴 기반 운동 시작
- 세트별 중량 및 횟수 기록
- 운동 완료 기록
- 과거 운동 기록 조회
- 운동별 성장 기록 조회

## Core Domain

- User
- Exercise
- Routine
- RoutineExercise
- WorkoutSession
- WorkoutExercise
- WorkoutSet
