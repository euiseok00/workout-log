# Workout Log 요구사항

## 1. 프로젝트 목적

개인용 헬스 루틴 및 운동 기록 웹 애플리케이션을 개발한다.

상용 서비스를 목표로 하지 않으며, 사용자가 자주 사용하는 운동 루틴을 저장하고 특정 날짜에 불러와 실제 운동 기록으로 활용하는 것을 목적으로 한다.

핵심 목표는 다음과 같다.

* 운동 종목 관리
* 운동 루틴 관리
* 날짜별 운동 기록
* 루틴 불러오기
* 세트별 운동 기록
* 과거 운동 기록 조회 및 수정

## 2. 사용자

초기 버전은 사용자 한 명만 사용하는 것을 전제로 한다.

따라서 다음 기능은 구현하지 않는다.

* 회원가입
* 로그인
* 사용자 관리
* 다중 사용자 지원

## 3. 운동 종목 관리

사용자는 운동 종목을 직접 등록하고 관리할 수 있다.

예시:

* 벤치프레스
* 인클라인 덤벨프레스
* 랫풀다운
* 스쿼트
* 레그프레스

지원 기능:

* 운동 종목 등록
* 운동 종목 목록 조회
* 운동 종목 수정
* 운동 종목 삭제

운동 종목이 이후 수정되거나 삭제되더라도 이미 저장된 과거 운동 기록에는 영향을 주지 않아야 한다.

## 4. 루틴 관리

루틴은 사용자가 반복해서 사용하는 운동 구성을 미리 저장해두는 기능이다.

루틴은 목표값을 의미하지 않는다.

사용자가 평소 사용하는 운동 구성과 세트 정보를 하나의 템플릿처럼 저장하고, 이후 특정 날짜의 운동에 그대로 불러오기 위한 기능이다.

### 4.1 루틴 기본 정보

루틴에는 다음 정보를 저장한다.

* 루틴 이름
* 운동 종목
* 운동 순서
* 운동별 세트 정보

### 4.2 루틴 세트 정보

루틴의 각 운동에는 여러 개의 세트를 저장할 수 있다.

각 세트에는 다음 정보를 저장한다.

* 무게
* 반복 횟수
* 세트 유형

각 세트의 값은 서로 다르게 설정할 수 있다.

예시:

Push A

벤치프레스

* 웜업 / 40kg × 15회
* 웜업 / 60kg × 10회
* 워킹 / 80kg × 10회
* 탑 세트 / 90kg × 5회

### 4.3 루틴 관리 기능

지원 기능:

* 루틴 생성
* 루틴 목록 조회
* 루틴 상세 조회
* 루틴 수정
* 루틴 삭제
* 루틴에 운동 추가
* 루틴에서 운동 삭제
* 운동 순서 변경
* 운동별 세트 추가
* 운동별 세트 수정
* 운동별 세트 삭제
* 세트 순서 변경

## 5. 루틴 불러오기

사용자는 특정 날짜의 운동 기록을 생성할 때 기존에 저장한 루틴을 불러올 수 있다.

예시:

저장된 Push A 루틴

벤치프레스

* 80kg × 10회
* 80kg × 10회
* 90kg × 5회

↓

2026-08-24 운동 기록에 Push A 불러오기

↓

해당 날짜에 맞게 수정

벤치프레스

* 80kg × 10회
* 85kg × 8회
* 90kg × 4회

루틴을 불러오면 루틴의 정보를 새로운 운동 기록으로 복사한다.

이후 해당 날짜의 운동 기록에서 다음 정보를 자유롭게 수정할 수 있다.

* 운동 종목
* 운동 순서
* 세트
* 무게
* 반복 횟수
* 세트 유형

해당 날짜의 운동 기록을 수정하더라도 원본 루틴은 변경되지 않는다.

또한 이후 원본 루틴을 수정하거나 삭제해도 이미 저장된 과거 운동 기록에는 영향을 주지 않는다.

## 6. 날짜별 운동 기록

사용자는 특정 날짜에 수행한 운동을 기록할 수 있다.

하나의 날짜에는 여러 개의 운동 기록을 생성할 수 있다.

예시:

2026-08-24

* 운동 기록 1
* 운동 기록 2

별도의 세션 이름은 필수로 입력하지 않는다.

같은 날짜의 여러 운동 기록을 서로 구분할 수 있으면 된다.

### 6.1 운동 기록 전체 메모

각 운동 기록에는 해당 운동 세션 전체에 대한 메모를 작성할 수 있다.

예시:

2026-08-24 / 운동 기록 1

메모:

오늘 수면이 부족해서 전체적으로 중량을 낮춤.

지원 기능:

* 메모 작성
* 메모 수정
* 메모 삭제

### 6.2 운동 기록 내 운동 관리

하나의 운동 기록에는 여러 운동 종목을 포함할 수 있다.

지원 기능:

* 운동 추가
* 운동 삭제
* 운동 순서 변경

### 6.3 운동별 메모

운동 기록에 포함된 각각의 운동에는 별도의 메모를 작성할 수 있다.

예시:

벤치프레스

메모:

오른쪽 어깨가 조금 불편해서 가동 범위를 줄임.

지원 기능:

* 운동별 메모 작성
* 운동별 메모 수정
* 운동별 메모 삭제

## 7. 세트 기록

각 운동에는 여러 개의 세트를 기록할 수 있다.

각 세트에는 다음 정보를 저장한다.

* 무게
* 반복 횟수
* 세트 유형
* 완료 여부

### 7.1 무게

무게 단위는 kg으로 고정한다.

무게는 소수점 둘째 자리까지 입력할 수 있다.

예시:

* 20kg
* 22.5kg
* 27.25kg

### 7.2 반복 횟수

각 세트의 반복 횟수를 저장한다.

예시:

* 5회
* 8회
* 10회
* 12회

### 7.3 세트 유형

각 세트는 하나의 세트 유형만 선택할 수 있다.

현재 지원하는 세트 유형:

* 웜업
* 워킹
* 탑 세트
* 실패

예시:

| 세트 | 유형   |   무게 |  횟수 |
| -- | ---- | ---: | --: |
| 1  | 웜업   | 40kg | 15회 |
| 2  | 워킹   | 80kg | 10회 |
| 3  | 탑 세트 | 90kg |  5회 |
| 4  | 실패   | 95kg |  3회 |

### 7.4 완료 여부

각 세트에는 완료 여부를 저장한다.

완료 여부는 해당 세트를 실제로 수행했는지를 나타낸다.

예시:

| 세트 |   무게 |  횟수 | 완료 |
| -- | ---: | --: | -- |
| 1  | 40kg | 15회 | O  |
| 2  | 80kg | 10회 | O  |
| 3  | 90kg |  5회 | X  |

### 7.5 세트 관리 기능

지원 기능:

* 세트 추가
* 세트 수정
* 세트 삭제
* 세트 순서 변경
* 세트 유형 변경
* 완료 여부 변경

## 8. 과거 운동 기록 조회

사용자는 날짜별로 과거 운동 기록을 조회할 수 있다.

지원 기능:

* 운동한 날짜 조회
* 특정 날짜의 운동 기록 목록 조회
* 특정 운동 기록 상세 조회
* 과거 운동 기록 수정
* 과거 운동 기록 삭제

과거 기록에는 당시 수행했던 정보가 그대로 유지되어야 한다.

## 9. 데이터 보존 원칙

운동 기록은 루틴이나 운동 종목과 독립적으로 과거 상태를 보존해야 한다.

예를 들어:

* 운동 종목 이름을 수정하더라도 과거 기록은 기존 상태를 유지할 수 있어야 한다.
* 운동 종목을 삭제하더라도 과거 기록은 삭제되지 않아야 한다.
* 루틴을 수정하더라도 과거에 해당 루틴을 불러와 작성한 운동 기록은 변경되지 않아야 한다.
* 루틴을 삭제하더라도 기존 운동 기록은 유지되어야 한다.
